Kafka Connect Console

Worker non charge.

Mode direct : le navigateur appelle l'URL Kafka Connect du champ base URL. Mode proxy transparent : la page appelle automatiquement /proxy/{env}, et le script PowerShell relaie vers l'URL reelle declaree dans connectors-env.json.
Page ouverte en file:// : le navigateur peut bloquer les appels vers DEV/UAT/STA/PROD avec CORS. Lance start-connectors-console.bat, ouvre http://localhost:8095/connectors.html, puis selectionne le mode Proxy transparent.
